# Monitoria — Fundamentos da Programação

Repositório destinado aos materiais da **Monitoria Voluntária de Fundamentos da Programação**, voltada aos cursos de Engenharia.

## 🎯 Objetivo

Este repositório tem como objetivo disponibilizar **resoluções de exercícios e vídeos de resolução**, auxiliando os alunos no estudo dos conteúdos abordados na disciplina e na prática de programação.

Os exercícios buscam trabalhar a construção de algoritmos e a implementação de soluções para diferentes problemas utilizando **programação estruturada**.

## 📚 Conteúdos

Os materiais do repositório abordam os seguintes conteúdos da disciplina:

### 1. Algoritmos e conceitos básicos

* Definição de algoritmos
* Tipos primitivos de dados
* Constantes e variáveis
* Expressões lógicas
* Expressões aritméticas

### 2. Estruturas de controle

* Desvio condicional
* Estruturas de repetição

### 3. Vetores e matrizes

* Definição de vetores
* Definição de matrizes
* Manipulação de vetores e matrizes

### 4. Modularização

* Procedimentos
* Passagem de parâmetros por valor
